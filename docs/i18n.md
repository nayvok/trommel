# Internationalization

The app currently uses a small runtime helper:

```rust
use trommel_core::i18n::{tr, set_language, Language};
let text = tr("Start", "Запустить");
```

`Language::System` resolves `LANGUAGE`/`LANG`; `En`/`Ru` force a language. The
setting is stored in `behavior.language` and applied at app start; changing it
requires an app restart. Source strings are English, Russian is a full mirror.

The GNOME extension uses `tr(en, ru)` based on `GLib.get_language_names()`.
Catalog descriptions and option labels use `*_en`/`*_ru` fields in TOML.

## Future gettext migration

The helper is intentionally isolated so it can be replaced with gettext without
touching call sites. When moving:

1. Add `gettext-rs` with `gettext-system` (glibc) to avoid static LGPL gettext.
2. Wrap strings with `gettext`/`ngettext`; keep the same English source.
3. Extract Rust strings with `xtr`, JS with `xgettext`.
4. Compile `po/ru.po` with `msgfmt`; install to
   `/usr/share/locale/ru/LC_MESSAGES/trommel.mo`.
5. Add `translation type="gettext"` to metainfo and `--podir=po` to the extension
   pack.
6. Never commit `.mo` files; keep `.pot` and `.po` in git.

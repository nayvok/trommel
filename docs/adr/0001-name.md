# ADR 0001: Name "Trommel"

Status: accepted.

A trommel is a real mining machine that screens and washes ore. It is a single
noun, 7 characters, easy to pronounce, directly related to the domain, and not a
trademark of another mining app. It pairs with a simple drum-and-gold icon and
does not tie the product to Pearl.

All identifiers derive from it: `io.github.nayvok.Trommel`,
`trommel@nayvok.github.io`, `trommel`/`trommeld`, `~/.config/trommel`.

# Trommel

[English](README.md) · **Русский**

Trommel — пульт управления NVIDIA-ригом на GTK4/libadwaita. Он хранит майнеры,
пулы, монеты, профили GPU и готовые пресеты, чтобы не превращать рабочий стол в
набор shell-скриптов.

> Trommel — менеджер, а не майнер. Бинарники майнеров скачиваются отдельно,
> одновременно работает только один майнер, а при остановке возвращаются
> стоковый лимит питания и частоты.

**Для кого:** домашний ПК с одной–тремя картами NVIDIA. Это локальная простая
альтернатива полноценной mining-OS, а не пульт удалённой фермы, не замена ОС и
не кошелёк. Начните с **простого режима**; продвинутые аргументы майнера
скрыты, пока вы их не включите.

## Ключевые возможности

- **Мульти-GPU дашборд** — температура, мощность, вентилятор, частоты, загрузка
  и хешрейт каждой карты; эффективность, когда майнер её отдаёт; мощность рига,
  самая горячая карта и графики по каждой карте в одном спокойном экране.
- **Пресет владеет ригом** — в пресете хранятся монета/алгоритм, пул, кошелёк,
  воркер, версия майнера, его опции и собственные настройки участия, питания и
  частот каждой карты. Смена пресета меняет всю конфигурацию GPU; новый пресет
  начинается со стока. Именованные **GPU-пресеты** сохраняют и переиспользуют
  шаблоны настройки карт.
- **Участие отдельных GPU** — выключенная карта исключается из активного
  майнера: она не передаётся майнеру и не настраивается. WildRig, SRBMiner и
  OneZero используют документированные device-флаги, а майнер без такого флага
  отказывается работать на части рига, вместо того чтобы тихо майнить на всех
  картах.
- **Библиотека майнеров и менеджер версий** — краткое описание, все
  установленные версии с пресетами, которые на них ссылаются, проверка и
  удаление, ссылка на upstream. Установки глобальные и версионированные: новая
  сборка не переписывает пресеты, старые версии остаются для отката, а версию,
  закреплённую пресетом, нельзя удалить. Комиссия показана разбивкой
  (майнер + пул = итого).
- **Безопасность по умолчанию** — перед настройкой снимается снимок стокового
  питания и частот каждой карты и восстанавливается при остановке. Работающий
  майнер никогда не перезапускается молча: изменения требуют явного
  **«Применить и перезапустить»** или **«Применить и остановить»**.
  Emergency-stop, guard и восстановление при старте закрывают падения и потерю
  сессионной шины.
- **Watchdog хешрейта** — по умолчанию выключен; при включении уведомляет о
  устойчивом падении хешрейта, а явный opt-in может перезапустить майнер через
  обычный путь с ограниченным числом попыток.
- **Локальная история** — демон хранит один замер в минуту примерно восемь дней
  и отдаёт его в диалоге History (1ч/24ч/7д), среднем за 24 часа и экспорте в
  CSV. Кошелёк, URL пула и телеметрия не сохраняются.
- **Трей и уведомления** — меню StatusNotifierItem с живым статусом,
  Start/Stop, показом окна и выходом, плюс desktop-уведомления о падении,
  ошибке и перегреве. При закрытии окна демон продолжает майнить.
- **Готовность к агентам** — JSON-статус и диагностика, `config diff/apply`,
  экспорт/импорт пресетов и опциональный MCP-сервер, по умолчанию только для
  чтения. Агент предлагает изменение; вы видите diff и подтверждаете.
- **Простой режим и двуязычный интерфейс** — английский и русский, светлая и
  тёмная схемы, системная тема GTK. Простой режим скрывает аргументы майнера и
  продвинутые строки частот.

## Поддерживаемая конфигурация

- Linux с GNOME Shell 50 (проверенная цель — Ubuntu 26.04), Wayland. Трей также
  работает в KDE Plasma 6; в GNOME нужен AppIndicator (Ubuntu поставляет его).
- NVIDIA GPU с рабочим драйвером и `nvidia-smi`.
- Для разработки: Rust 1.92+, `libgtk-4-dev`, `libadwaita-1-dev`, `pkg-config`.

AMD/Intel, X11-специфичные пути и другие рабочие столы не поддерживаются.

## Установка

Trommel распространяется через **GitHub Releases**; apt-репозитория и PPA нет.
Скачайте последний `.deb` со страницы
<https://github.com/nayvok/trommel/releases/latest> и установите:

```bash
sudo apt install ./trommel_amd64.deb
```

Или запустите установщик: он скачает последний `.deb`, проверит SHA-256 и
поставит пакет:

```bash
curl -fsSLO https://github.com/nayvok/trommel/releases/latest/download/trommel-install.sh
bash trommel-install.sh
```

Пакет содержит приложение, `trommeld`, polkit-хелпер, desktop-entry, иконки и
metainfo. Демон запускается по требованию через D-Bus; настройка GPU работает
без пароля для пользователя, который ставил пакет. Обновление — установка нового
`.deb`; удаление — `sudo apt remove trommel`.

Путь для разработчика собирает и ставит приложение в пользовательскую сессию:

```bash
./install.sh             # сборка, установка и включение user-сервиса
./install.sh --no-helper # без polkit-хелпера (без OC)
```

RPM, AppImage и Flatpak **не выпускаются**; причины и статус —
в [docs/development.md](docs/development.md#formats).

## Первый запуск

На чистой установке **пресета нет**. Дашборд показывает найденные карты и
объясняет, что нужен пресет. **«Создать пресет»** открывает редактор: выберите
монету, укажите пул, кошелёк и воркер, установите версию майнера и настройте
карты. **Start** снимает снимок каждой включённой карты, применяет питание и
частоты и запускает ровно один майнер. Stop возвращает снимок.

Полный сценарий, включая пулы, комиссии, локи частот и диагностику, — в
[руководстве пользователя](docs/user-guide.md).

## CLI

```bash
trommel status [--json]        # краткая сводка или контракт статуса
trommel start / stop / toggle
trommel preset list / use <id>
trommel miner list / install / import / verify / remove
trommel bench --minutes 3
trommel diagnose --json > diagnostics.json
trommel config diff proposed.json
trommel config apply proposed.json --restart
trommel mcp                    # MCP-сервер только для чтения, stdio
```

Демон — единственный источник истины. GUI можно закрыть; майнер продолжит
работу.

**Лицензия ещё не выбрана.** Прежнее заявление о MIT удалено; в AppStream

## Дисклеймер

Майнинг потребляет электроэнергию и выделяет тепло. Вы отвечаете за
оборудование, электричество, комиссии пула, безопасность кошелька и местные
законы. Начинайте с консервативных лимитов питания и следите за первым запуском.

# Security policy

Please report vulnerabilities privately to the maintainer (see the GitHub
profile) rather than in a public issue. Include reproduction steps, affected
version and whether the polkit helper or a miner binary is involved.

Supported version: the current `0.2.x` line. The project does not distribute
miner binaries; report vulnerabilities in those binaries to their upstream
authors.

Never include seed phrases, private keys or full wallet files in a report. A
public wallet address is not a secret but can be redacted.
